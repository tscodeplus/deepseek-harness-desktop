DeepSeek Harness Desktop 首个候选发布版本：采用 Tauri 2 桌面壳 + Node sidecar 架构，将 DeepSeek Harness 封装为原生桌面应用，支持 **Windows x64**、**macOS Intel (x64)** 与 **macOS Apple Silicon (arm64)** 三个平台。

## ✨ 主要特性

- **Tauri 2 原生桌面壳**：单实例、系统托盘（关闭到托盘、托盘菜单）、开机自启、深色模式跟随
- **Node sidecar 架构**：内置官方 Node.js 运行时，同源加载 dsh WebUI（`http://127.0.0.1:3080`），本地访问、不暴露远程端口
- **进程生命周期管理**：sidecar 心跳防孤儿（shell 意外退出后自动清理）、Windows Job Object 兜底、退出时优雅关闭 dsh
- **三平台安装包**：Windows NSIS 安装器 + macOS dmg（含更新元数据 `latest.yml` / `latest-mac.yml`）
- **CI 自动化**：每次提交自动跑测试；tag 推送自动构建三平台安装包并在 macOS 上做启动冒烟测试

## ⚠️ 已知限制

- 无代码签名：Windows SmartScreen 与 macOS Gatekeeper 会提示未知开发者，请按系统指引放行
- 外部 subagent 后端（claude-code / codex / acp / dsh-sdk）驱动已随包附带，但对应的 CLI（`claude` / `codex`）需要用户自行安装并加入 PATH；应用不再附带 Claude Agent SDK 的 ~260MB 原生二进制（dsh 运行时从 PATH 解析 `claude`，该二进制不会被使用）

DeepSeek Harness Desktop's first release candidate: a Tauri 2 shell + Node sidecar desktop app wrapping DeepSeek Harness, for **Windows x64**, **macOS Intel (x64)** and **macOS Apple Silicon (arm64)**.

## ✨ Highlights

- **Tauri 2 native shell**: single instance, system tray (close-to-tray, tray menu), launch at login, dark-mode follow
- **Node sidecar architecture**: bundled official Node.js runtime, same-origin dsh WebUI (`http://127.0.0.1:3080`), local-only access
- **Process lifecycle management**: heartbeat-based anti-orphan cleanup, Windows kill-on-close job object, graceful dsh shutdown on exit
- **Three-platform installers**: Windows NSIS + macOS dmg, with updater metadata (`latest.yml` / `latest-mac.yml`)
- **Automated CI**: tests on every commit; tag pushes build all three platforms and run macOS launch smoke tests

## ⚠️ Known limitations

- Unsigned builds: Windows SmartScreen and macOS Gatekeeper will warn about the unknown developer; follow the system prompts to allow
- The external subagent backend drivers (claude-code / codex / acp / dsh-sdk) are bundled, but their CLIs (`claude` / `codex`) must be installed by the user and available on PATH; the app no longer ships the ~260MB Claude Agent SDK native binary (dsh resolves `claude` from PATH at runtime, so that binary was never used)
