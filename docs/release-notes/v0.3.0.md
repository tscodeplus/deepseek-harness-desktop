DeepSeek Harness Desktop v0.3.0 正式版：跟随 DeepSeek Harness 升级并完善插件的安装和管理体验。

## 🆕 主要更新

- **上游升级**：基于 DeepSeek Harness **0.1.0-rc.7**（GitHub commit [`99f6f02f`](https://github.com/deepseek-ai/deepseek-harness/tree/99f6f02fecdb7dff40c3fbc9470f5907c29f74ca)）构建，获得 node-pty 1.2 beta、插件设置卡片、Job Panel 子代理、MCP/ACP 持久化附件等上游改进
- **完善插件的安装与管理体验**：托盘菜单入口、更新前先做版本检测、优化说明文案和提示窗口的位置
- **自动跳过最新版本**：安装插件时若插件已是最新版本，自动跳过，无需重复安装

## ✨ 主要特性

- **插件管理**：内置 pnpm，无需命令行即可从桌面端安装与管理插件（含插件管理器窗口）
- **开箱即用**：无需安装 Node.js、无需命令行，安装后配置 API Key 即可开始使用
- **支持三平台**：Windows x64、macOS Intel (x64)、macOS Apple Silicon (arm64)
- **支持在线更新**：应用内自动检查新版本；Windows 一键下载安装，macOS 引导打开 Releases 页面下载
- **桌面体验**：系统托盘、关闭到托盘、开机自启、深色模式

## ⚠️ 已知限制

- 无代码签名：Windows SmartScreen 与 macOS Gatekeeper 会提示未知开发者，请按系统指引放行
- 外部 subagent 后端（claude-code / codex / acp / dsh-sdk）驱动已随包附带，但对应的 CLI（`claude` / `codex`）需要用户自行安装并加入 PATH；应用不再附带 Claude Agent SDK 的 ~260MB 原生二进制（dsh 运行时从 PATH 解析 `claude`，该二进制不会被使用）

> This project is a community desktop build based on [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness), not an official DeepSeek product.

DeepSeek Harness Desktop v0.3.0 stable: follows DeepSeek Harness upgrades and improves the plugin install & management experience.

## 🆕 What's new

- **Upstream upgrade** — built on DeepSeek Harness **0.1.0-rc.7** (GitHub commit [`99f6f02f`](https://github.com/deepseek-ai/deepseek-harness/tree/99f6f02fecdb7dff40c3fbc9470f5907c29f74ca)), bringing node-pty 1.2 beta, plugin settings cards, Job Panel subagents, and MCP/ACP persistent attachments
- **Better plugin install & management** — tray menu entry, version check before updating, improved copy and prompt-window placement
- **Skip up-to-date plugins** — when installing a plugin that is already at its latest version, the install is automatically skipped

## ✨ Highlights

- **Plugin management** — bundled pnpm; install and manage plugins from the desktop, no terminal needed (with a plugin manager window)
- **Install & go** — no Node.js install, no terminal; just install, add your API key, and start using it
- **Three platforms** — Windows x64, macOS Intel (x64), and macOS Apple Silicon (arm64)
- **Auto-updates** — checks for new versions in-app; one-click install on Windows, opens the Releases page on macOS
- **Desktop experience** — system tray, close-to-tray, launch at login, dark mode

## ⚠️ Known limitations

- Unsigned builds: Windows SmartScreen and macOS Gatekeeper will warn about the unknown developer; follow the system prompts to allow
- The external subagent backend drivers (claude-code / codex / acp / dsh-sdk) are bundled, but their CLIs (`claude` / `codex`) must be installed by the user and available on PATH; the app no longer ships the ~260MB Claude Agent SDK native binary (dsh resolves `claude` from PATH at runtime, so that binary was never used)
